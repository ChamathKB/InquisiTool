This represents a typical host page where the widget would be embedded. Click Load Widget above to inject the survey widget with your configuration, then look for the 💬 button in the bottom-right corner.


To get an API key, open the Campaigns page in the frontend, then click Copy Widget on any campaign — it generates a key and copies the embed snippet automatically. Paste the campaign ID and key into the fields above, then click Load Widget.
