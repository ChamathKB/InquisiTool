# Embeddable Survey Widget

A lightweight vanilla JS widget that can be embedded in any HTML page to run a campaign survey via a floating chat popup.

## How It Works

1. Generate a campaign API key via the authenticated API
2. Build the widget bundle
3. Drop a `<script>` tag into any HTML page

The widget talks directly to the public `/public/survey` endpoint using the campaign API key — no Keycloak token required for respondents. All responses are recorded as anonymous.

## Building the Widget

```bash
make widget-build
```

This compiles `widget/src/widget.js` and outputs `inquisitool/static/widget.iife.js`, which is served by FastAPI at `/static/widget.iife.js`.

## Generating a Campaign API Key

Call the key generation endpoint with your Keycloak Bearer token:

```bash
curl -X POST http://localhost:8000/campaigns/<campaign-id>/generate_key \
  -H "Authorization: Bearer $TOKEN"
```

Response includes the `api_key` field:

```json
{
  "campaign_id": "<campaign-id>",
  "campaign_name": "...",
  "api_key": "<generated-key>",
  ...
}
```

Calling the endpoint again regenerates the key and invalidates the previous one.

## Embedding in an HTML Page

Add the following `<script>` tag to any HTML page:

```html
<script
  src="https://your-api.com/static/widget.iife.js"
  data-api-url="https://your-api.com"
  data-campaign-id="<campaign-id>"
  data-api-key="<api-key>"
></script>
```

| Attribute | Description |
|---|---|
| `data-api-url` | Base URL of your InquisiTool API |
| `data-campaign-id` | UUID of the campaign to run |
| `data-api-key` | Key generated by `/campaigns/{id}/generate_key` |

## API Endpoints

| Method | Path | Auth | Description |
|---|---|---|---|
| `POST` | `/campaigns/{id}/generate_key` | Bearer token | Generate / regenerate campaign API key |
| `POST` | `/public/survey` | `X-API-Key` header | Public survey endpoint used by the widget |
| `GET` | `/static/widget.iife.js` | None | Serve the widget bundle |

## Development

To iterate on the widget source:

```bash
cd widget
npm install
npm run build   # outputs to inquisitool/static/
```

The widget source is at `widget/src/widget.js` — plain vanilla JS, no framework dependencies.
